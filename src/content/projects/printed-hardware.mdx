## Rack extension for Cherith Farms

Cherith Farms is a CSA farm. I designed, built, and donated a second, strut-supported layer for one of its racks.

| Item | Value |
| --- | --- |
| Connectors | 18, printed in ASA |
| Connector designs | 7, parametric |
| Design live load | 20 psf |
| Sizing method | Hand beam analysis |
| Governing safety factor | ≈ 8 |
| Actual load | ≈ 4 to 6 psf |
